# WhisperType-Android-Downloads

Public signed APK releases and update feed for WhisperType Android. The source repository is private; no source code or signing material is published here.

Download the [latest signed APK](https://github.com/chaosmanage/WhisperType-Android-Downloads/releases/latest/download/app-release.apk) and compare its SHA-256 hash with the accompanying `app-release.apk.sha256` release asset. Android will ask you to approve installation from your browser. Do not uninstall the old app to upgrade; that would erase local settings and credentials.

The currently available v1.2.14 APK is a verified, unchanged copy of the previously published release. Builds through v1.2.15 still check the old repository for updates, so they need one manual upgrade to v1.2.16 or newer when it is published. Newer builds check this public repository for updates automatically and link to the signed APK for user-approved installation. No silent installation is performed.
